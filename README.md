# Power BI Sales & Profit Analysis Dashboard

## 📊 Project Overview

This project is an interactive **Power BI Sales & Profit Analysis Dashboard** developed to analyze sales performance, profitability, product performance, discounts, quantities sold, and customer-related information.

The dashboard provides multiple views of the business data and allows users to interact with the report using date filters, product filters, customer filters, and promotion filters.

The project covers the period from **2020 to 2024** and demonstrates the use of **Power BI, Power Query, DAX, data modeling, slicers, interactive visualizations, and data analysis**.

---

## 🎯 Business Objectives

The main objectives of this project are to:

* Analyze overall sales performance.
* Track total profit and quantity sold.
* Identify the top and bottom performing products.
* Analyze sales trends over time.
* Understand the impact of promotions and discounts.
* Compare sales, profit, and units sold between different periods.
* Provide interactive filtering capabilities for business users.
* Present detailed transaction-level data for further analysis.

# 📑 Dashboard Pages

## Page 1 – Top & Bottom 5 Product Analysis

This page focuses on identifying the best and lowest-performing products.

The dashboard analyzes:

* Top 5 Products by Sales
* Bottom 5 Products by Sales
* Top 5 Products by Quantity
* Bottom 5 Products by Quantity
* Top 5 Products by Profit
* Bottom 5 Products by Profit

This helps identify products that contribute significantly to revenue and profitability, as well as products with relatively poor performance.

---

## Page 2 – Overview Dashboard

The Overview page provides a high-level view of the business performance.

It includes:

* Sales trend by period
* Average discount by promotion category
* Profit vs Net Sales analysis
* Number of orders
* City-level information

The sales trend visualization helps understand how sales changed between 2020 and 2024.

The promotion analysis provides insight into discount values associated with different promotional campaigns.

---

## Page 3 – Requirement 1: Period-Based Performance Analysis

This page allows users to select date ranges and analyze business performance for the selected period.

The dashboard compares:

* Total Sales
* Total Profit
* Total Quantity Sold

Date slicers are used to provide an interactive way of selecting the required periods.

This enables users to perform period-based analysis and understand changes in sales, profitability, and units sold.

---

## Page 4 – Sales, Profit & Units Sold Comparison

This page provides a visual comparison between two selected date periods.

The report compares:

* Total Sales
* Total Profit
* Total Units Sold

Separate date slicers allow users to select the two periods that they want to compare.

This can be useful for analyzing performance between different months, years, promotional periods, or other business periods.

---

## Page 5 – Edit Interaction

This page demonstrates the use of **interactive filtering and visual interactions in Power BI**.

Users can filter the report using fields such as:

* Customer Name
* Promotion Name

The page demonstrates how selections from slicers can control and interact with report visuals.

This improves the usability of the dashboard and allows users to explore the data based on specific business requirements.

---

## Page 6 – Detailed Table Analysis

The final page provides a detailed transaction-level view of the dataset.

The table contains fields such as:

* Order ID
* Customer ID
* Date
* Discount Percentage
* Discount Value
* Net Sales
* Price per Unit
* Product ID
* Profit
* Promotion ID
* Total Sales
* Units Sold

Users can use slicers for:

* Date
* Customer Name
* Product Name

This page provides detailed information behind the aggregated dashboard visuals and can be used for transaction-level analysis.
